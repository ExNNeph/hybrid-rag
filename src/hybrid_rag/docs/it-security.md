# IT and security for employees

## Your laptop

Every employee gets a MacBook with disk encryption, managed by IT. Do not turn off the encryption, the
firewall or automatic updates. Updates must be installed within 7 days after they are offered.

## Passwords and accounts

Use the company password manager for all work accounts and turn on two-factor authentication wherever
possible. Never reuse a work password for private accounts. Shared accounts are only allowed if IT has set
them up in the password manager.

## Lost or stolen devices

Report a lost or stolen laptop or phone to it@talvi.example within 1 hour, also outside working hours.
IT will lock and wipe the device remotely. If it was stolen, also report it to the police and send the
report number to IT.

## Phishing

If an email asks for your password, a payment or a gift card, do not click on any link. Forward the email
as an attachment to phishing@talvi.example and delete it. Nobody at Talvi will ever ask for your password.

## Installing software

Software from the self-service catalogue can be installed without asking. For anything else, open a request
with the form IT-12 in the IT portal; IT checks licence and data protection within 3 business days.
Browser extensions that read website content are not allowed.

## Using AI tools

You may use the AI assistants approved by IT for work. Never paste customer data, passwords or source code
of unreleased features into AI tools that are not on the approved list.
